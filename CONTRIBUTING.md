# Contributing to FlowPilot

Thank you for contributing to FlowPilot, an AYORAI open-source engineering project focused on versioned human-in-the-loop workflows.

## Workflow
Issue -> Fork -> Branch -> Commit -> Pull Request -> CI -> Review -> Merge

## Before opening a change
1. Search existing Issues and Pull Requests.
2. Open an Issue first for substantial changes.
3. Keep changes focused and backwards-compatible when practical.
4. Add or update tests for behavior changes.
5. Update documentation when public behavior changes.

## Good contributions
Documentation, tests, examples, bug fixes, performance improvements, validation, security hardening, and developer tooling are welcome.

## Pull Requests
Explain what changed, why it changed, how it was validated, and any compatibility or security considerations. Do not commit secrets, credentials, private data, or generated caches.
